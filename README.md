## O que eu sei fazer

**Sistemas embarcados**
Bring-up de display SPI do zero — ST7789 240×240 sem pino CS dedicado, wiring e driver na mão.
Seleção de MCU por critério de engenharia, não por hype: ESP32-S3, RP2040 e Pi Zero 2 W comparados por integridade e confiabilidade do dado.
Leitura de sensores ambientais e inerciais, motor brushless com ESC, NFC/RFID como gatilho físico.
Eletrônica digital de base: decodificador BCD→7 segmentos, implementação só com NAND, comparadores, montagem em protoboard.

**Automação de processos reais**
Automação de interface Windows em aplicação Delphi legada com pywinauto e pyautogui: detecção de popup, sequenciamento de teclado, reconhecimento por imagem quando não existe handle.
Integração com API bancária para emissão em lote e pipelines planilha → formulário.
Higiene de repositório: identificação e remoção de dado sensível, `.gitignore` defensivo, entendimento de que apagar arquivo não apaga histórico.

**IA aplicada**
Servidores MCP em FastMCP: composição por `mount()`, estado JSON persistente entre chamadas, recursos embutidos como contrato de metodologia.
Orquestração no Claude Code: subagents, hooks, memória e estratégias de redução de consumo de contexto.
Spec-driven development — PRD, specs numeradas e plano de execução por fases antes da primeira linha.
E o julgamento de quando *não* usar IA: muita coisa que vendem como IA é automação simples bem feita.

**Engenharia de software**
C com Makefile duplo BSD/GNU, múltiplos compiladores e dialetos, binários para Linux e FreeBSD, versionamento em RCS antes do Git.
Python com `uv` e src-layout. React Native, Expo e Firebase.

**Método de pesquisa**
Revisão sistemática de literatura com string de busca replicável entre Scopus e Web of Science.
Metodologia ISO 14044 / ILCD aplicada a Avaliação de Ciclo de Vida.
Propagação de incerteza e comparação de métodos em medição experimental.
